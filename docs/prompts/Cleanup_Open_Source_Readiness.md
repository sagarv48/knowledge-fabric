# Cleanup Prompt: Open Source Readiness

Use this prompt to enforce public, vendor-neutral language in repository documentation.

```text
Refactor this repository into a vendor-neutral open-source project named Knowledge Fabric.

Remove or rewrite references to:
- product-specific platform names
- internal architecture names
- internal workflow names
- internal security procedures
- internal tools and project codenames

Replace with vendor-neutral terms:
- Knowledge Fabric
- enterprise documentation
- runtime MCP adapter
- knowledge organization framework
- intent orchestration layer

Update:
- README.md
- docs/*
- prompts/*
- config examples

Create a summary listing:
1. Files modified
2. Proprietary references removed
3. Private content isolated
4. Remaining risks, if any
```
