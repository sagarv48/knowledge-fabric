# Repository Boundaries

This repository is Phase 1: Knowledge Fabric.

## In scope

- Document ingestion
- Chunking
- Embedding provider abstraction
- Lexical retrieval
- Vector retrieval
- Hybrid retrieval
- Evidence packages
- MCP retrieval API
- Retrieval evaluation

## Out of scope

- Workflow execution
- Product-specific runtime integrations
- Product-specific MCP adapters
- Case creation
- Approval workflows
- Production credentials
- Enterprise-private source content

## Related future repositories

- intent-fabric: intent planning and approval framework
- knowledge-fabric-enterprise-adapters: private enterprise integration adapters
