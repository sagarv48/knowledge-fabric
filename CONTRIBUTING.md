# Contributing

Thank you for contributing to Knowledge Fabric.

## Development principles

- Keep changes vendor-neutral.
- Preserve phase boundaries documented in `docs/repo-boundaries.md`.
- Prefer small, focused pull requests.
- Add or update documentation when behavior changes.

## Pull request expectations

1. Describe the problem and the approach.
2. Include test or validation notes relevant to the change.
3. Keep public documentation free of proprietary references.

## Code of conduct

Be respectful, constructive, and collaborative in all project interactions.
